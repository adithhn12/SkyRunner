# 🎮 SkyRunner

A 2D platformer game built with **Godot** featuring platforming, exploration, collectibles, and level progression.

## 🎮 Play Online

[▶️ Play SkyRunner](https://adithhn12.github.io/SkyRunner/)

## ✨ Features

- 🏃 2D platforming
- 🗺️ Exploration-based levels
- 🪙 Collectibles
- 🏆 High-score tracking
- 💾 Local high-score saving
- 🌐 Playable directly in the browser

## 🛠️ Built With

- Godot Engine
- GDScript

## 📂 Project Structure

SkyRunner/
├── assets/          # Game assets
├── scenes/          # Godot scenes
├── player.gd        # Player logic
├── coin.gd          # Collectible logic
├── high_scores.gd   # High-score system
├── project.godot    # Godot project configuration
└── ...

## 🚀 Running Locally

1. Clone the repository.
2. Open the project in **Godot Engine**.
3. Run the project from the Godot editor.

## 🌐 Web Version

SkyRunner is exported for the web and hosted using **GitHub Pages**, allowing the game to be played directly from a browser without installing anything.
